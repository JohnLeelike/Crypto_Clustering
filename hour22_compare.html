Greedy Max PnL: Hour-22 (UTC) Filter Comparison

$100 start, $5 per trade. Three ways of handling the one hour (22:00 UTC) that showed a persistent negative edge across both halves of the backtest.

A. Baseline: greedy max-PnL selection run on all hours, untouched.
B. Pre-filter: hour-22 events removed from every candidate's event pool before the greedy selection runs, so the algorithm re-optimizes around cleaner data.
C. Post-filter: the same baseline (A) selection, then hour-22 trades are simply stripped out of the already-chosen set afterward.
